WR Energia Solar 🚀☀️

Bem-vindo ao repositório do WR Energia Solar, um site desenvolvido com React.js, TypeScript, Swiper.js e Tailwind CSS, proporcionando uma interface moderna e responsiva para exibir serviços de energia solar.

📌 Tecnologias Utilizadas

React.js - Framework para a interface do usuário.

TypeScript - Tipagem estática para um código mais robusto.

Vite - Ferramenta de build rápida para projetos React.

Tailwind CSS - Estilização moderna e responsiva.

Swiper.js - Biblioteca para criar um carrossel de imagens.

🚀 Como Rodar o Projeto

1️⃣ Requisitos

Antes de iniciar, certifique-se de ter instalado:

Node.js (versão mais recente) - Baixar aqui

Gerenciador de pacotes: npm ou yarn

2️⃣ Instalação

No PowerShell, navegue até a pasta do projeto e instale as dependências:

npm install

ou, se estiver usando yarn:

yarn install

3️⃣ Executando o Servidor

Para iniciar o servidor local:

npm run dev

Acesse no navegador:

http://localhost:5173

🔥 Funcionalidades do Site

Home (Hero.tsx): Destaque para os serviços oferecidos.

Sobre (About.tsx): Informações sobre a empresa WR Energia Solar.

Serviços (Services.tsx): Lista os serviços de instalação e manutenção.

Galeria de Obras (Gallery.tsx): Exibe um carrossel de imagens com instalações solares concluídas.

Contato (Contact.tsx): Exibe telefone, Instagram e botão para WhatsApp.

Botão de WhatsApp (WhatsAppButton.tsx): Link direto para conversar com a empresa.
